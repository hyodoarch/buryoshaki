## ノートの表示の種類： .center
- 個別ノート（article-title）
	- ヘッダー： .page-header
		- [x] date: p ≫ 文字サイズ：14px、文字色： \#808080 ≫ title の上にするOK! ≫ 左右マージン 0 にする
		- [x] title: h1 ≫ 文字サイズ：25px
		- [x] subtitle: p ≫ 太字にし、前後に「―」を付ける
		- [x] tags: ul li ≫ 文字サイズ：13px、背景色：\#F0F0F0, ボーダー色：\#D0D0D0
	- 本文： article
		- [x] 上記テーブル ".center article の文字サイズ"  を参照
		- [x] 「無聊写記について」、「プロフィール」も同じ
- カテゴリー表示（folder-page）、タグページ表示（tag-page）
	- ヘッダー： .page-header
		- [x] フォルダ名、タグ名：h1 ≫ 文字サイズ：25px
	- 本文：article は無し
	- ノートタイトルのリスト表示
		- [x] ノート件数： p
		- ノートタイトルリスト： ul li
			- [x] ボーダー ≫ 太さ：1px
			- [x] date: p ≫ 文字サイズ：14px、文字色： \#808080 ≫ title の上にする
			- [x] title: h3 ≫ 文字サイズ：21px、本当は h2 になるのか？
			- [x] subtitle: p ≫ 太字にし、前後に「―」を付ける ≫ 現状ついていない
			- [x] tags: ul li ≫ 個別ノートの表示に合わせる
- トップページ表示（recent-notes）
	- ヘッダー： .page-header
		- [x] title: h1 ≫ 文字サイズ：25px
	- 本文： article
		- [x] 上記テーブル ".center article の文字サイズ"  を参照
	- ノートタイトルのリスト表示： .page-footer
		- [x] 最近のノート： p ≫ 太字、大きさ21px
		- ノートタイトルリスト： ul li
			- [ ] 水平線 または ボーダーが欲しい

			- [x] title: h3 ≫ 文字サイズ：21px ≫ 現状は17.92px
			- [x] subtitle: p ≫ 太字にし、前後に「―」を付ける
			- [x] tags: ul li ≫ 現状でOK
