## デバイス間の同期の検討
- 当初は Self-hosted LiveSync + IBM Cloudant を使っていたが、iPhone との同期が上手く行かないことが多くなった。
- Dropbox を使っているので、Remotely Save への移行も検討した。
- LiveSync の作者によると、IBM Cloudant で問題を経験したらしく、Fly.io をお勧めしているらしい。
- ChatGPTによると、LiveSync は下図のような仕組みらしい。
```
Windows
  ↓
PouchDB (local DB)
  ↓
CouchDB(Fly.io)
  ↑
PouchDB (local DB)
  ↑
iPhone

  ↑
PouchDB
  ↑
iPad
```
- 2026-06-20 Fly.io のアカウントを取り、couchDB に移行した。
- Fly.io は有料だが、容量追加ができるようである。最初の7日間は無料。しかしデータベースを稼働させるには、クレカ情報が必要。
## Self-hosted LiveSync の設定
1. LiveSync をインストール
2. [Setup CouchDB on fly.io](https://github.com/vrtmrz/obsidian-livesync/blob/main/docs/setup_flyio.md) を読む
3. [setup-flyio-on-the-fly-v2.ipynb](https://github.com/vrtmrz/obsidian-livesync/blob/main/setup-flyio-on-the-fly-v2.ipynb) を開き、`Open in Colab` ボタンをクリック。
4. region に Tokyo を選び全てのブロックを実行する。画面の `[ ]` をマウスオーバーすると`▶` が表示される。`▶` をクリックするとブロックが実行される。
5. `Copy setup URI` ボタンで obsidian://setuplivesync?settings= に続く暗号をコピーし、近くにパスフレーズが表記されているので、それもコピーする。
6. LiveSync を有効化し、Setup URI, Passphrase を張り付ける。
7. データを送る。向きに注意 Local → Remote
8. iPhone は、QRコードを使うと簡単に同期できる。データ転送の向きは Remote → Local
## Self-hosuted LiveSync の同期設定
1. LiveSync 同期とする。
2. `Compute revisions for chunks → true`
   `ファイルごとのカスタマイズ同期 → true`
   `チャンクサイズを最適化する → 60`
   `データベースサイズ通知の設定 → 800MB`
## 初めて iPhone を同期させる場合
 - Self-hosted LiveSync は手動でインストールする。
 - デスクトップPCで QR コードを表示させ、カメラで読み込むと obsidian へ移動する。
 - 下記のオプションは、②を選択する。
	 1. I am setting up a new server for the first time / I want to reset my exsting server.
	 2. My remote servet is already set up. I want to join this device.
	 3. The remote is already set up, and the configuration is compatible (or got compatible by this operation).
- Data retrieval scheduled のオプションは、②を選択する。
	1. compare time and take newer
	2. overwrite all with remote files
	3. use the datailed flow
	4. cancel
- how to handle extra existing local のオプションは、①を選択する。
	1. delete local files if not on remote（ローカルファイルがリモートにない場合は削除します）
	2. keep local files even if not on remote
	3. cancel all and reboot
## Hidden File Sync を有効化
- 設定 ≫ セットアップ（爺アイコン） ≫ 「高度な機能を有効かする」 を On
- 設定 ≫ セレクタ―（信号アイコン） ≫ Hidden Files
	- Target patterns : `^\.obsidian\/`
	- Ignore patterns : 
	   `\/obsidian-livesync\/`
		`\/workspace$`  
		`\/workspace.json$`  
		`\/workspace-mobile.json$`
	- Add default patterns : `Cross-platform` ボタンをクリックと上記の一部が追加される。
	- git の regex が 2パターンあるが、必要らしい。
- 隠しファイルの同期
	- Merge
	- Fetch ≫ リモートの隠しファイルをローカル側で取得
	- Overwrite ≫ ローカルの隠しファイルでリモート側を上書きする
- コアプラグインの設定の同期
	- 事務所PCのコアプラグインの設定がiPhone側に同期していないことがあった。事務所PCの設定値を変化させるとそれがトリガーとなって iPhone の設定値が同期した。
