無聊写記は、2004年に、私的な写真日記としてスタートしました。その頃の私は赤瀬川原平のファンで大きな影響を受けており、日常・非日常で見過ごされてしまう光景を探していました。私はそのような写真にロラン・バルトの言うところの「プンクトゥム」を感じるいたと思います。2007年に初めてデジタル一眼レフを買ったとき、とてもうれしかったのですが、仕事以外ではほとんど使用していません。それというのも iPhone のカメラがあまりに高機能なためスナップや仕事の記録は私にとってこれで十分になってしまったからです。この 20年で写真に対する興味は、薄れたわけではありませんが、なんだか全く違うものに変化してしまったように思います。現在は、写真よりもコンピュータ、アート、建築のノートが多く、自分自身の指向の変遷の記録のようになっております。
## Obsidian について
メモの活用について昔から興味があり、社会人になりたての頃は、京大式カードで記録していました。Palm の流行時には HanDBase で遊んでおりました。2003年に Microsoft OneNote が発売されたときはすぐに買いました。Evernote は 2010年から使用しはじめ、現在でも仕事でかなり使っている方だと思います。Notion が出たとき、そのスペックと可能性に非常に興味をもちましたが、思い付きのメモを取るには少し使いにく、学習障壁も高いため導入を見送っていました。その後、Markdown ファイルを扱うノートアプリが盛り上りを知り、いくつか試した後、Obsidian を日々の ToDo を管理するデイリーノートとして使い始めました。
## ココログ → MT → MTOS → WordPress → Obsidian + Quartz へ
- 2000年初頭のブームでココログを始めた。
- その後、レンタルサーバでMovableTypeを設定して使い始めた。
- MovableTypeの有料化などで、MTOSを経てWordPressを使い始めた。
- 2010年以降、webサイトは、モバイル対応する必要があった。
- wordpressでのモバイル対応が面倒で、仕事もプライベートも忙しく、ブログは5年ほど中断していた。
- obsidian publish というサービスがあることを知った。
- obisidian でブログを管理すれば、とてもよさそうである。
- 調べているうちに Quartz という MarkDownコンテンツをウェブサイトに変換するアプリの存在を知る。
- git や github も以前から勉強してみたかった。
